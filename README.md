# README — Inferno OS

## Introduction

Inferno is a lightweight distributed operating system developed by [Bell Labs](https://www.bell-labs.com/?utm_source=chatgpt.com). It is designed for building portable and secure distributed applications that can run across different hardware and network environments.

---

# Features

* Lightweight and efficient
* Distributed computing support
* Portable across platforms
* Secure communication system
* Uses the Limbo programming language
* Runs applications through the Dis Virtual Machine
* Supports networking and resource sharing

---

# System Components

## 1. Kernel

Handles:

* Process management
* Memory management
* Device control
* File systems

## 2. Dis Virtual Machine

* Executes compiled Limbo programs
* Makes applications portable

## 3. Limbo Language

* Programming language for Inferno
* Designed for distributed systems
